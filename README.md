# ☕ BROWN Coffee

### A slower kind of luxury.

BROWN Coffee is a premium coffee shop website concept featuring an elegant editorial design, warm neutral colors, and a refined coffee-house atmosphere.

## ✨ Features

- Responsive design for desktop and mobile
- Elegant hero section and coffee imagery
- Interactive menu category filters
- Live menu search
- Mobile navigation
- Smooth scrolling and section navigation

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- GitHub Pages
